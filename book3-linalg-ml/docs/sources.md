## Details carried into the outline

- **Ordering decision (documented deviation):** we follow Strang/VMLS — concrete computation first
  (elimination, matrices, then abstract vector spaces and linear maps), orthogonality and least
  squares as the geometric payoff, determinants mid-book before eigenvalues (Strang order), NOT
  banished to the end (Axler). Axler's abstract-first rigor is borrowed for ch.3–4 proofs, not
  for ordering.
- **Figure styles borrowed:** 3b1b-style map grid deformations (ch.4–5); sphere→ellipsoid SVD
  picture (ch.10); colah's square-area probability diagrams (ch.12, 15); small-multiples for
  Gram–Schmidt and elimination (ch.1, 5); gradient field on contours (ch.11, 14).
- **Numerical experiments borrowed as patterns:** VMLS's data-first regression in early chapters;
  MML's notebook-per-application; Pishro-Nik's simulate-the-theorem habit; Kochenderfer's
  algorithm-listing style.
- **Learner stalls (from MML issue tracker and errata culture):** determinant sign flips;
  gradient-vs-derivative semantics; vector-valued gradients/Jacobian layout; multivariate
  expectation; A^TA eigenvalue confusion; projection-matrix misuse; Gram–Schmidt context;
  positive-definiteness tests; PCA formula details. Each becomes an explicit Common Mistakes item.
- **CS229 gating:** the current quarter's notes require Stanford login; for later chapter work,
  use public archived note versions only, and log them when opened.
