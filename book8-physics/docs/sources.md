## What the research changed in the outline (summary)

1. **Order: momentum before energy** — adopted from MIT 8.01SC (and Morin's combined energy/momentum treatment) over the OpenStax/AP order; elastic collisions are then *revisited* inside the energy chapter once \(K\) exists (mirrors 8.01SC weeks 5→9).
2. **Scope bound** = AP Physics C units 1–13 verbatim + the F=ma additions (fluids, data analysis) — fluids gets a short optional appendix since AP C omits it but F=ma does not.
3. **Difficulty scheme** = three textual bands anchored to real venues: [easy] ≈ AP-C multiple-choice / lower-half F=ma; [medium] ≈ AP-C free-response part / upper F=ma; [hard] ≈ USAPhO/APhO short problem / Gnädig one-star+. Star precedent from Morin and Gnädig.
4. **Worked-example register** = Strategy → Solution → Significance/check (OpenStax format), matching the template's strategy-before-solution rule.
5. **Capstone** = single final part (20 original contest problems, full solutions), structured like Gnädig/Krotov (problems → hints → solutions) rather than scattered per chapter.
6. **E&M order** = 8.02SC/OpenStax order kept: fields → Gauss → potential → capacitors → circuits → B fields → sources → Faraday → inductance → Maxwell → EM waves.
