## Concrete details captured for use

- **Small datasets (downloadable from any machine):** sklearn toy sets — `iris`, `digits` (8×8 MNIST), `wine`, `breast_cancer`, `diabetes`, `california_housing`; seaborn sets — `penguins`, `tips`, `titanic`; MNIST (via `torchvision`/`fetch_openml`); Fashion-MNIST; CIFAR-10 (`torchvision`); Tiny Shakespeare ~1 MB (char-level text); FordA time-series (timeseriesclassification.com, used by USAAIO 2026 R2); OpenML tabular sets (`adult`, `titanic`) via `sklearn.datasets.fetch_openml`; AG News small subset for text classification.
- **How sources do from-scratch-vs-library:** D2L implements every model in raw framework API AND gives the concise API version side by side (d2l package wrappers hide boilerplate); CS231n assignments require NumPy-from-scratch layers tested by numerical gradient check, then PyTorch versions in assignment 2–3; UDL notebooks leave blanks the reader fills against printed expected outputs; USAAIO Round 2 mandates from-scratch attention and bans loading prebuilt attention blocks. Adopted pattern per chapter: `code/chNN/*_scratch.py` (NumPy or raw PyTorch), `code/chNN/*_lib.py` (sklearn/PyTorch modules), and a printed comparison table or figure (same train/test split, same seed).
- **From-scratch vs library boundary chosen:** NumPy for classical methods (ch3–6); raw `torch.Tensor` + manual autograd-free gradient code for ch7's backprop demo; `torch.nn` modules but hand-rolled training loop for ch8+; `nn.MultiheadAttention`-free attention built from primitives in ch10–11 (mirrors USAAIO's constraint); only ch14+ assume library stack.
- **Reproduction candidates (CPU / free-tier GPU, evaluated in outline ch18):** (a) LeNet-5 on MNIST — LeCun et al. 1998 headline ~99% test accuracy; minutes–1 h on CPU, fully verifiable, primary candidate; (b) ResNet-20 on CIFAR-10 — He et al. 2016 reports ~8.75% test error; trainable on free-tier GPU in ~1–2 h, demonstrates residual learning; stretch candidate; (c) double-descent curve — Belkin/Nakkiran et al., MNIST-1D-style small study; cheapest, teaches evaluation skepticism; fallback candidate.
- **RL running example:** 10-armed testbed (S&B §2.3) plus Gymnasium `CartPole-v1` — both CPU-trivial.
- **Fast-moving facts to date-stamp at writing time:** PyTorch, scikit-learn, transformers, gymnasium versions (pin in `code/README.md`); HF model-hub conventions; LM-eval practice and agent-framework vocabulary (already shifted once between Dec 2024 and Oct 2026 — Anthropic's own post carries a retraction note).
