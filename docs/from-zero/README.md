# From-zero pass (books 1–6 and 8)

What this pass adds to every book except book 7:

1. **`start.tex` — "Start here: from zero"** (unnumbered front-matter chapter, `\input` after the table of contents).
   The background the book silently assumed: C++ in ten minutes (book 1), why prove things (2), calculus/notation primer (3),
   Python + vectors (4), SI prefixes and rearranging formulas (5), what a market and a return are (6),
   units / derivative / vectors (8), and a table of how the book connects to the others.
2. **Three boxes at the top of every chapter** (generated by `apply_boxes.py` from `boxes_bookN.py` and `think_bookN.py`):
   - *Before you start* (`rulebox`) — prerequisites with a one-line recap, citing other books by number (ch02+ and some ch01).
   - *After this chapter you can* (`wins`) — concrete things the reader can do.
   - *How to think about this* (`principle`) — the concept / way of approaching the chapter's problems, in a teacher's voice.
3. **"First attempt" worked examples** that show the naive approach failing before the right one
   (book 1 ch04, book 2 ch01, book 5 ch02, book 6 ch01–02, book 8 ch01–05), with real captured output where there is code.
4. **"Why this exists" paragraph** at the top of each book's ch01.

Re-run `python3 docs/from-zero/apply_boxes.py` from the repo root; it is idempotent (blocks are fenced by `% from-zero:` markers).
`ins.py` inserts the marked "first attempt" examples the same way.

## Voice
Warm teacher, not terse senior engineer: explain *why* an idea works and *how to approach* a problem, in plain words, with a
concrete example before a formal statement. Define a term where it first appears.

## Not in this pass
Figures (separate thread), Watch / Further-reading boxes (separate thread), book 7 (separate thread).
Pre-existing, not touched: 6 overfull hboxes >3 pt in book 1 (`figures/fig97-template.tex`).
